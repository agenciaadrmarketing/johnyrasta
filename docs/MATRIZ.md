# Matriz: requisito → capacidade antiga → decisão V2 → teste de aceite

Atualizada em 19/10/2026 (Fase 1). "Antigo" refere-se à leitura estática do pacote `johny-rasta.tar.gz`; nada ali foi validado em produção.
